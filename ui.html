テンプレートから新規作成

テンプレートを選び、欄を埋めると、新しい「無題」の文書ができます。できるのは、欄のない、ふつうの Markdown です（どのツールで開いても、同じに見えます）。


      

    

    

  





  

    
保存の設定

    
自動保存は、編集中の内容を「下書き」として別の場所に書きます。文書のファイルは書き換えません（保存は、これまでどおり、保存ボタンで行います）。異常終了や Windows の再起動のあと、次の起動のときに、復元を提案します。保存したときと、「保存しない」を選んだときは、下書きを消します。

    

    

    
上書き保存の前に、元のファイルの内容を退避します（バックアップ）。退避は、置き場全体（ファイルごとではありません）で、新しいものから次の数だけ残します。

    

    

    

  





  

    
保存されないまま終了した内容があります

    
前回、保存しないまま終わった編集中の内容（自動保存の下書き）です。復元すると、その内容が編集欄に入ります（まだ保存はされません。内容を確かめて、保存してください）。

    

    

  





  

    
修正の確認

    
次のように直します。上が直す前、下が直したあとです。直したあとは、Ctrl+Z で、まとめて元に戻せます。

    

    

  





  

    
検査のルール

    
チェックを入れた規則で検査します。直すかどうかは、書いた人が決めます（自動では直しません）。文書の中に <!-- lint-disable MD009 --> と書くと、その行から止められます。

    
    

    

  





  

    
表・データの取り込み

    
Excel のセルをコピーして、下の欄に貼り付ける（Ctrl+V）か、CSV・JSON のファイルを読み込みます。同じデータから、Markdown の表と、JSON（Vega-Lite などで使うデータ）を作れます。JSON のデータ（[{…}, …] の形）を貼り付けて、表にすることもできます。

    

    

    

      
      
      
      
    

    

      
      
    

    

      
      
      
    

    

    

  





  

    
表示フォントの設定

    
「画面」はボタン・一覧など、「編集欄」は文章を書く場所、「本文」「見出し」「コード」はプレビュー（印刷・PDF を含む）の文字、「図・グラフ」は Mermaid と Vega-Lite の文字です。フォント名は1つだけ設定します。入力欄を押すと候補が出て、文字を打つと絞り込まれます。各行の「既定」でその部分を既定に戻せます。変更はすぐ画面に反映され、次回の起動にも引き継がれます。
